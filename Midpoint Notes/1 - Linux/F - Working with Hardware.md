### dmesg
![[Pasted image 20260714174842.png]]
The command `dmesg | grep -i usb` in Linux is used to filter kernel log messages related to USB devices. Let’s break it down:

- `dmesg`: or ==Diagnostic Message== displays kernel ring buffer messages. These are system-level logs generated by the Linux kernel, often including hardware detection, driver loading, and error messages.
- `grep`: or ==Global Regular Expression Print== command searches text for patterns. Here, it’s used to filter only lines containing "usb".
- `-i option`: Makes the search case-insensitive, so it matches "USB", "usb", "Usb", etc.
- `usb`: The keyword being searched for in the kernel logs.

### udevadm
![[Pasted image 20260714175421.png]]
`udevadm` is the Linux command-line tool used to manage and interact with _udev_, the device manager for the Linux kernel. It lets you query device information, monitor hardware events, trigger device actions, and control the behavior of the `systemd-udevd` daemon.

- **info**: Query the udev database for details about a device (e.g., `/dev/sda` or `/sys/class/block/sda`).
- **monitor**: Watch real-time kernel and udev events (useful when plugging/unplugging USB devices).
- **trigger**: Force udev to process events for devices, simulating hotplug actions.
- **settle**: Wait until all pending udev events are handled.
- **control**: Adjust runtime behavior of `systemd-udevd` (e.g., reload rules).
- **test**: Debug how udev rules apply to a specific device.

| Tool        | Purpose                  | Typical Use Case                                             |
| ----------- | ------------------------ | ------------------------------------------------------------ |
| **dmesg**   | Kernel ring buffer logs  | Check if the kernel detected hardware (e.g., USB plugged in) |
| **udevadm** | udev device manager tool | Query device properties, monitor udev events, manage rules   |

### lspci
![[Pasted image 20260714180747.png]]
The `lspci` command in Linux is used to list all PCI (Peripheral Component Interconnect) devices on your system. PCI devices include things like graphics cards, network adapters, sound cards, USB controllers, and other hardware connected via the PCI bus.

### lsblk
![[Pasted image 20260714181505.png]]
The `lsblk` command in Linux is used to list information about all available block devices on your system. Block devices are storage devices that transfer data in fixed-size blocks — such as hard drives, SSDs, USB drives, and partitions.

### lscpu
![[Pasted image 20260714182043.png]]
The `lscpu` command in Linux is used to display detailed information about the CPU architecture of your system. It pulls data from `/proc/cpuinfo` and other system sources, presenting it in a clean, structured format.

- **lscpu**: Summarizes CPU architecture details.
- Shows information such as:
    - Number of CPUs, cores, and threads
    - CPU family, model, and vendor
    - CPU speed (MHz)
    - Cache sizes
    - NUMA nodes and topology
    - Virtualization support

### lsmem
![[Pasted image 20260714182345.png]]
The `lsmem` command in Linux is used to display information about the system’s memory blocks. Unlike `free` or `top`, which show memory usage, `lsmem` focuses on the **memory layout** — how physical memory is organized and presented to the kernel.

- **lsmem**: Lists memory blocks and their attributes.   
- Shows details such as:    
    - Memory block size       
    - Range of addresses        
    - Online/offline status       
    - Removable capability (hotplug support)      
- Useful for **NUMA systems**, **memory hotplugging**, and **low-level memory management**.

### lshw
![[Pasted image 20260714182516.png]]
The `lshw` command in Linux is a powerful tool that provides detailed information about the hardware configuration of your system. It digs deep into the system and reports on CPU, memory, storage, network interfaces, buses, and more.

- **lshw**: Lists hardware details in a structured format.
- Can output in **human-readable**, **short summary**, or **machine-readable formats** (HTML, XML, JSON).
- Requires root privileges (`sudo lshw`) to show complete information.

![[Pasted image 20260714182630.png]]
The `sudo` command in Linux stands for **“superuser do”**. It allows a permitted user to run commands with elevated privileges — typically as the **root user**. Since many administrative tasks (like installing software, modifying system files, or managing hardware) require root access, `sudo` is the safe way to temporarily gain those privileges without logging in as root.
