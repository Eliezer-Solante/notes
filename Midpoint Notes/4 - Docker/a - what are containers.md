Docker <mark style="background: #FFF3A3A6;">**containers**</mark> are lightweight, portable environments that package an application and all its dependencies so it can run consistently across different systems.** They isolate processes but share the host’s operating system kernel, making them faster and more efficient than traditional virtual machines.
